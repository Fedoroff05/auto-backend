# Auto Service Backend API

Высоконагруженный RESTful API & Real-time WebSocket сервис для площадки онлайн-объявлений по продаже автомобилей (аналог Auto.ru / Drom).

Проект разработан на языке **Go** с использованием принципов **Clean Architecture**, реляционной СУБД **PostgreSQL**, in-memory хранилища **Redis** и S3-совместимого объектного хранилища **MinIO**.

---

## Технологический стек

* **Язык программирования:** Go (1.23+)
* **Архитектура:** Clean Architecture (Domain, Usecase, Repository, Delivery)
* **База данных:** PostgreSQL 16 (драйвер `pgx/v5` с пулом соединений `pgxpool`)
* **Кэширование:** Redis 7 (клиент `go-redis/v9`)
* **Медиа-хранилище:** MinIO S3 (`minio-go/v7`)
* **Real-time протокол:** WebSockets (`gorilla/websocket`)
* **HTTP-роутер:** `go-chi/chi/v5` + CORS Middleware
* **Аутентификация:** Stateless JWT (HMAC-SHA256, Access + Refresh токены)
* **Безопасность:** Хэширование паролей адаптивным алгоритмом `bcrypt`
* **Документация API:** OpenAPI 2.0 / Swagger UI (`swaggo`)
* **Контейнеризация:** Docker Compose

---

## Основной функционал

1. **Аутентификация и RBAC:**
    - Регистрация и вход с валидацией данных.
    - Хранение паролей с солью через `bcrypt`.
    - Выпуск токенов Access (15 мин) и Refresh (30 дней).
    - Ролевая модель: `user`, `moderator`, `admin`.

2. **Каталог объявлений (Listings):**
    - Полный CRUD (создание, чтение, редактирование, удаление).
    - Проверка прав: редактировать/удалять может только создатель или модератор.
    - Поиск по фильтрам (марка, модель, цена от/до, год выпуска).
    - Пагинация (`limit` / `offset`).

3. **Медиа-хранилище (MinIO S3):**
    - Загрузка картинок через `multipart/form-data`.
    - Валидация форматов (JPEG, PNG, WebP) и размера до 10 МБ.
    - Генерация UUID-имен для исключения перезаписи файлов.
    - Прямая отдача картинок в браузер.

4. **Оценка рыночной стоимости:**
    - Расчет средней цены по аналогам того же года (+- 2 года).
    - Запасной расчет (fallback) по первой машине в базе, если аналогов нет.

5. **Избранное с Redis:**
    - Хранение связи пользователь-машина в PostgreSQL.
    - Атомарные счетчики популярности в Redis (`INCR` / `DECR`).

6. **Real-time Чат (WebSockets):**
    - Двусторонний обмен сообщениями между покупателем и продавцом.
    - Архитектура Hub/Client с разделением чтения и записи.
    - Сохранение истории диалогов в PostgreSQL.
    - Авторизация по JWT при подключении к сокету.

7. **A/B Тестирование:**
    - Деление аудитории 50/50 через FNV-1a хэш от UUID.
    - Запись аналитических событий в PostgreSQL колонку типа `JSONB`.

Архитектура проекта
````
├── cmd/

├── config/

├── docs/                         # Сгенерированные файлы Swagger
├── internal/
│   ├── domain/                   # Сущности, интерфейсы, ошибки
│   ├── handler/
│   │   ├── http/                 # Роутер Chi, CORS, middleware
│   │   │   ├── middleware/       # JWT Auth и RBAC проверки
│   │   │   ├── response/         # Форматирование ответов API
│   │   │   └── v1/               # Контроллеры эндпоинтов
│   │   └── ws/                   # WebSocket Hub и сокет-клиенты
│   ├── repository/
│   │   └── postgres/             # Слой работы с базой (pgxpool)
│   └── usecase/                  # Бизнес-логика приложения
├── migrations/                   # SQL миграции
└── pkg/                          # Утилиты (bcrypt, jwt, redis, s3, postgres)
